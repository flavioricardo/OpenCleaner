    What it leaves out

    Popular PC cleaners turned into subscription storefronts: “issues found” alerts to sell the paid version, telemetry on by default, offers during setup. OpenCleaner does the cleaning and stops there.

    • No telemetry

      The app sends nothing about you or your PC. There is no server and no account.

    • Nothing to sell

      No locked features, no subscription, no offers for other products.

    • Nothing in the background

      No service, no startup entry, no self-updates.

    • Nothing hidden

      Every cleaning item shows which files will go, and the code is on GitHub.

    • Online only when you ask

      Only Update programs (winget) and Update drivers (Windows Update) connect, both Microsoft sources.

    • Passwords stay put

      Passwords, cookies, history and form data start unchecked and ask before they go.

    Everything a system cleaner does

    Screens from the app, in English and Portuguese: it follows the Windows language.

    Your PC on one screen: how much of the drive is used, how much can be freed, orphaned registry entries, programs that open with Windows, outdated programs and gaming settings to undo. Nothing changes until you click Clean.

    More than 70 items across Windows, browsers and apps, and only installed programs show up. Analyze first to see how much space comes back; double-click a result to see its files. It also reads the community winapp2.ini rules.

    Finds entries that point to files and programs that no longer exist, in seven categories, and offers a .reg backup before fixing. To restore it, double-click the file.

    Finds what “FPS optimizers” left behind, such as Game Mode turned off or the Xbox sign-in apps removed, and puts back the Windows default. On laptops, it sets each game to the high-performance graphics card. There is no “boost” button.

    Searches Windows Update for drivers certified and published by the manufacturers and installs the ones you check, creating a restore point first. Programs update through winget, Microsoft's package manager.

    • Update programsThrough winget; installers are hash-checked before they run.
    • Uninstall programsWith size and date, and clears entries of programs already gone.
    • StartupDisables the same way Task Manager does, so it can be undone.
    • Disk analyzerHow much space each file type takes, and the largest files of each.
    • Duplicate finderFiles with identical contents; the copies go to the Recycle Bin.
    • Automatic cleaningRun OpenCleaner.exe /AUTO from Task Scheduler; results go to a log.

    Know what each click does

    Analyzing never deletes anything. Destructive actions ask first, and most of them can be undone.

    ActionWhat happensCan it be undone?
    Analyze, Check, SearchReads only. Nothing changes.Nothing to undo
    Run cleanerDeletes the files of the checked items, without the Recycle BinNo
    Fix checked (Registry)Deletes the orphaned entries you checkedYes, with the .reg backup offered first
    Move to Recycle BinDuplicates and disk analyzer files go to the Recycle BinYes
    Apply checked (Gaming)Puts the checked settings back to the Windows defaultYes, with the .reg backup offered first
    Install checked (drivers)Installs through Windows UpdateYes, with the restore point created first

    • changes settings
    • removes something
    • Windows and user profile folders (Windows, System32, Program Files, Documents, Desktop) are never wiped as a whole, not even by winapp2 rules.
    • Junctions and symbolic links are not followed.
    • Firefox history is not deleted, because it lives in the same file as your bookmarks.
    • A registry entry is only flagged when its file provably doesn't exist; network paths are ignored.
    • In Options > Never delete, you can protect any folder from every rule.

    Frequently asked questions

    Is it safe to clean the registry?

    Orphaned entries don't slow Windows down; removing them is tidying up, not a performance boost. That's why OpenCleaner is conservative: it only flags what provably points to nothing and offers a backup first. If something goes wrong, double-click the saved .reg file.

    Will I lose my passwords or be signed out of websites?

    Not with the default selection. Cookies, passwords, form data and history start unchecked; when you check them, the app explains what you'll lose.

    Does OpenCleaner boost FPS?

    It doesn't promise FPS. The Gaming page undoes what drags performance down (Game Mode off, a desktop power plan on a laptop, a game running on the integrated graphics card) and shows the Windows options that help, explaining each one.

    How is it different from CCleaner?

    OpenCleaner is completely free, open source and has no telemetry. It doesn't have CCleaner's performance optimizer or free-space wiper, and it uses winget and Windows Update, Microsoft's official sources, to update programs and drivers.

    Does it work offline?

    Yes. Only Update programs and Update drivers need a connection.

    How much space will I get back?

    It depends on how you use your PC: browser and app caches usually add up to hundreds of MB or a few GB. The analysis shows the exact amount before anything is deleted.
